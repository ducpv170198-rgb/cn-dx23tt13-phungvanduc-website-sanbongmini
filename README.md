# Website Đặt Sân Bóng Mini (Laravel 12)

Hệ thống quản lý và đặt lịch thuê sân bóng đá mini trực tuyến, giúp người dùng dễ dàng tra cứu khung giờ trống, đặt sân nhanh chóng và hỗ trợ chủ sân quản lý lịch trình, doanh thu hiệu quả.

---

## 1. Thông tin sinh viên thực hiện
* **Họ và tên:** Phùng Văn Đức
* **Mã lớp:** DX23TT13
* **Giảng viên hướng dẫn:** Nguyễn Nhứt Lam
* **Đồ án:** Đồ án Chuyên ngành CNTT

---

## 2. Công nghệ sử dụng
* **Backend:** PHP 8.4, Laravel 12 Framework
* **Frontend:** Blade Template, Bootstrap 5 / Tailwind CSS, JavaScript
* **Cơ sở dữ liệu:** MySQL
* **Công cụ quản lý:** GitHub, Composer

---

## 3. Các tính năng chính (Cập nhật tiến độ)

### 👤 Phân hệ Khách hàng
- [ ] Đăng ký, đăng nhập tài khoản và phân quyền.
- [ ] Tìm kiếm sân bóng theo khu vực, loại sân (sân 5, sân 7) và khung giờ.
- [ ] Xem trạng thái sân trống theo thời gian thực và thực hiện đặt sân.
- [ ] Quản lý lịch sử đặt sân và hủy lịch (theo quy định).

### 🛠️ Phân hệ Quản trị viên (Chủ sân)
- [ ] Quản lý danh sách sân bóng, thiết lập bảng giá theo khung giờ (giờ thường / giờ cao điểm).
- [ ] Duyệt, xác nhận hoặc từ chối yêu cầu đặt sân từ khách hàng.
- [ ] Thống kê doanh thu theo ngày, tháng, năm.
