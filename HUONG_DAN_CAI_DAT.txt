SAN BONG MINI — BAN TICH HOP 24/11/2026
Windows / Laragon / PHP 8.4 / MySQL 8 / Composer 2 / Node 22
Giai nen vao C:\laragon\www\sanbong-mini 
Bat MySQL trong Laragon. Tao database TRONG sanbong_mini bang HeidiSQL.
Mo Laragon Terminal tai thu muc du an, chay lan luot:
  copy .env.example .env
  composer install
  php artisan key:generate
  php artisan migrate
  php artisan db:seed --class=SanBongMiniSeeder
  php artisan sanbong:create-admin admin@sanbong.local
  npm ci
  npm run build
  php artisan serve
Mo http://127.0.0.1:8000/app
Dang nhap bang tai khoan admin vua tao. Khong chay seeder tren du lieu that: seeder co the dat lai ton kho.
Email: mac dinh ghi log, khong gui that. Cau hinh SMTP trong .env neu can; chay php artisan queue:work va php artisan schedule:work trong hai terminal rieng.
VietQR: dien FIELDLY_BANK_BIN, FIELDLY_BANK_ACCOUNT, FIELDLY_BANK_ACCOUNT_NAME trong .env. QR chi huong dan chuyen khoan, admin phai doi soat.
Khong co SQL du lieu cu trong goi. Migration tao cau truc va seeder tao san, gia, dich vu mau.
Kiem thu: tao database rieng sanbong_mini_test; sao chep .env thanh .env.testing, doi DB_DATABASE sang sanbong_mini_test, sau do php artisan migrate --env=testing va php artisan test. Khong chay test tren database that.
